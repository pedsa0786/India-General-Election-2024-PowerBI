# 🇮🇳 India General Election Results 2024 – Power BI Dashboard

## 📌 Project Overview
This project presents a comprehensive **Power BI dashboard** analyzing the **India General Election 2024** results.  
It provides insights at **national, state, constituency, and party levels** using interactive and drill-through dashboards.

---

## 🎯 Objectives
- Analyze seat distribution across **NDA, I.N.D.I.A., and Other parties**
- Understand **state-wise and constituency-wise political trends**
- Enable **deep drill-through analysis** for detailed insights
- Provide a **clean, user-friendly, interactive UI**

---

## 📊 Dashboards Included

1. **Landing Page**
   - Central navigation hub

2. **Overview Analysis**
   - Total seats, alliance-wise performance
   - NDA vs I.N.D.I.A. vs Others

3. **State Demographics Analysis**
   - State-wise seat distribution
   - Map-based visualization

4. **Political Landscape by State**
   - Party-wise seat share
   - Donut charts & grids

5. **Constituency Analysis**
   - Winning, Runner-up, 2nd Runner-up
   - Vote share, EVM & Postal votes

6. **Details Grid**
   - Exportable constituency-level data
   - Drill-through enabled
